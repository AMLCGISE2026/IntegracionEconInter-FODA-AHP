# Evaluación Multicriterio del Potencial de Integración Económica de Paraguay en el MERCOSUR: Un Análisis FODA-AHP con Enfoque de Economic Fitness, año 2024

Este repositorio contiene los códigos, bases de datos y resultados utilizados en el desarrollo del trabajo.

El repositorio tiene como objetivo facilitar la consulta, trazabilidad y reproducibilidad de los procedimientos computacionales y análisis desarrollados en la investigación.

El estudio combina dos enfoques principales:
1. **Economic Fitness**, utilizado para analizar las capacidades productivas y la complejidad económica de Paraguay y del MERCOSUR.
2. **FODA-AHP**, utilizado para evaluar comparativamente los factores internos y externos relacionados con el potencial estratégico de integración económica.
Los resultados de ambos enfoques fueron integrados posteriormente mediante el modelo multicriterio desarrollado en la investigación.


## Contenido del repositorio
## 1. Modelo matemático computacional de Economic Fitness

Contiene el código desarrollado en Python para el cálculo del indicador de Economic Fitness, implementado mediante un Notebook de Jupyter.

**Archivo:** `economic_fitness_2024.ipynb`

El Notebook incluye el procesamiento de los datos de comercio internacional, la construcción de la matriz país-producto y el cálculo iterativo de Economic Fintess y Product Complexity.

## 2. Resultados de Economic Fitness

Contiene los resultados obtenidos para los modelos considerados en el estudio:
-	`M0.xlsx`, correspondiente a los datos de exportación de los 230 países considerados
-	`M1.xlsx`, correspondiente al modelo que incluye al MERCOSUR

## 3.	Modelo multicriterio FODA-AHP
Contiene el archivo Excel utilizado para el desarrollo del modelo multicriterio, incluyendo la base de datos empleada, la estructura FODA, las matrices de comparación y los cálculos correspondientes al método AHP (Analytic Hierarchy Process).

**Archivo:** `BDD_AHP_2026.xlsx`

## 4.	Base de datos en bruto
Contiene las fuentes de información utilizadas para la construcción de los indicadores y subcriterios de análisis FODA-AHP.

La información se encuentra organizada en carpetas de acuerdo con cada subcriterio.
